
# Sistema Integral de Gestión - Software FJ

## Fase 4 - Programación UNAD

Curso: Programación (213023)

## Descripción

Sistema desarrollado en Python mediante programación
orientada a objetos para gestionar clientes, servicios
y reservas de la empresa ficticia Software FJ.

## Funcionalidades

- Registro y validación de clientes.
- Reserva de salas.
- Alquiler de equipos.
- Asesorías especializadas.
- Creación, confirmación y cancelación de reservas.
- Cálculo de costos.
- Manejo de excepciones personalizadas.
- Registro de errores y eventos en sistema.log.
- Simulación de 10 operaciones.

## Tecnologías

- Python 3
- Visual Studio Code
- GitHub

## Ejecución del programa

Abrir una terminal en la carpeta del proyecto y ejecutar:

python main.py

## Ejecución de pruebas

Para ejecutar las 10 simulaciones:

python pruebas.py

## Archivos principales

- main.py
- cliente.py
- servicios.py
- reserva.py
- excepciones.py
- registro.py
- pruebas.py

## Base de datos

El proyecto no utiliza bases de datos.
La información se maneja mediante objetos en memoria.

## Evidencias

El archivo sistema.log permite consultar los errores
y eventos registrados durante las pruebas.
