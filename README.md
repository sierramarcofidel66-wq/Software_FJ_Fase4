
# Sistema Integral de Gestión de Clientes, Servicios y Reservas

## Software FJ - Fase 4

Curso: Programación 213023
Universidad Nacional Abierta y a Distancia - UNAD

## Descripción

Aplicación desarrollada en Python mediante programación
orientada a objetos para la gestión de clientes, servicios
y reservas de la empresa ficticia Software FJ.

El sistema permite controlar errores y continuar ejecutando
operaciones aun cuando se presentan datos incorrectos.

## Funcionalidades

- Registro y validación de clientes.
- Reserva de salas.
- Alquiler de equipos.
- Asesorías especializadas.
- Confirmación y cancelación de reservas.
- Procesamiento y cálculo de costos.
- Aplicación de descuentos e impuestos.
- Validación de disponibilidad de servicios.
- Manejo de excepciones personalizadas.
- Encadenamiento de excepciones.
- Registro automático de errores.
- Administración mediante listas internas.
- Diez simulaciones principales.
- Pruebas complementarias de validación.

## Programación orientada a objetos

El proyecto incorpora:

- Abstracción.
- Herencia.
- Polimorfismo.
- Encapsulación.
- Clases y métodos abstractos.
- Métodos con parámetros opcionales.
- Manejo de listas internas.

## Archivos del proyecto

- main.py
- cliente.py
- servicios.py
- reserva.py
- gestion.py
- excepciones.py
- registro.py
- pruebas.py

## Requisitos

Python 3.

No requiere instalar librerías externas.

## Ejecutar el programa

Abrir una terminal en la carpeta del proyecto y escribir:

python main.py

## Ejecutar las pruebas

En la misma terminal escribir:

python pruebas.py

El resultado esperado es:

RESUMEN: 10 de 10 pruebas correctas.

También se ejecutan pruebas complementarias.

## Registro de errores

El programa genera automáticamente sistema.log.

Este archivo contiene fechas, eventos, errores y detalles
de las excepciones detectadas durante la ejecución.

No es necesario crear sistema.log manualmente.

## Almacenamiento

El programa no utiliza bases de datos.

Los clientes y las reservas se administran mediante
objetos y listas internas en memoria.

## Verificación del proyecto

El tutor puede descargar el repositorio de GitHub,

No se requieren rutas absolutas ni configuraciones
específicas del computador del estudiante.
